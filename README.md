# Servidor Python Básico

Proyecto de aprendizaje sobre redes usando Python y sockets.

## Características

* Servidor TCP
* Acepta conexiones de clientes
* Envía mensajes
* Consola de administración
* Comando para apagar el servidor

## Requisitos

* Python 3.x

## Ejecución

```bash
python servidor.py
```

## Comandos

### Apagar servidor

```text
apagar
```

Detiene el servidor y cierra el puerto.

## Tecnologías utilizadas

* Python
* Socket
* Threading

Aprender conceptos básicos de:

* Redes

* Sockets
* Multithreading
* Comunicación cliente-servidor
